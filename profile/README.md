# VoxArbor

Українська озвучка відео з YouTube прямо в браузері.

- **Як це працює:** скрипт у браузері → сервер VoxArbor → вузли спільноти розпізнають мову, перекладають українською й озвучують.
- **Готові переклади** доступні всім безкоштовно.
- **Вузол** — це ваш ПК, який ділиться потужністю: хто ділиться, той може перекладати й озвучувати нові відео.

| Репозиторій | Що там |
|---|---|
| [userscript](https://github.com/voxarbor/userscript) | Скрипт для браузера |
| [node](https://github.com/voxarbor/node) | VoxArbor Node: розпізнавання, переклад, озвучка, мовці |

Сайт: [voxarbor.com](https://voxarbor.com)
